# Approved visual baseline

The user selected **E2B v2 and Modal v1** as the gold standards for the roster.
Use both actual sheets as image references for subsequent generation and edits.

- Stylized adult arcade/anime proportions, angular silhouettes and expressive faces.
- Crisp selective dark pixel outlines, broad readable color shapes, restrained shading ramps.
- Detail concentrated in face, signature gear and accent edges; simplified cloth folds.
- Distinct provider palettes and silhouettes within one shared rendering style.
- Avoid both realistic tactical/grunge rendering and cute oversized-head mascot art.

Reference sheets establish rendering, proportions and detail density. Do not copy
their character designs, costumes or poses onto unrelated fighters.

Preserve original sheets when revising. Inspect a new fighter beside E2B and Modal
at the same displayed size before calling the style matched. Existing roster art
has not all been harmonized to this baseline yet.

Judge Jev uses the same portrait rendering in a fixed waist-up camera. Eight
planned states: neutral, studying, skeptical, impressed, deliberating, verdict,
half-blink and closed-eye blink. Reactions in a future product must follow actual
evaluation state, not imply fabricated judgments. This local preview is art only.
